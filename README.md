# ФАЛЬКОН — цифровой признак автомобиля

Версия v4 (16.09.2026): настоящий датасет подключён, проведены обучение и сравнение моделей на отдельных ID. Архив v4 включает экспериментальные нейросетевые веса. Качество пока низкое, это не финальное конкурсное решение. Команды нейросетевого запуска, формат query/gallery и ограничения: [docs/DATASET_V4.md](docs/DATASET_V4.md). Измеренные показатели выбранной модели находятся в `metrics.json` архива v4.

Рабочий MVP сервиса для регистрации визуального цифрового отпечатка автомобиля и поиска похожих автомобилей по фотографии. Номерной знак не является обязательным: поиск опирается на цвет, форму, распределение деталей и контуры изображения.

## Что уже работает

- регистрация автомобиля по изображению и необязательным метаданным;
- формирование нормализованного визуального вектора;
- хранение профилей в SQLite;
- поиск ближайших профилей по косинусному сходству;
- веб-интерфейс и JSON API;
- обработка заданного в ТЗ `BBox` в формате `x, y, width, height`;
- OpenAPI-схема по адресу `http://127.0.0.1:8000/openapi.json`;
- явный ответ `Top-N` или отказ при недостаточной уверенности;
- генератор демонстрационных изображений;
- автоматические тесты алгоритма и хранилища.
- аудит датасета и воспроизводимый расчёт retrieval-метрик.

## Быстрый запуск

Это запуск классического демонстрационного алгоритма, не нейросети. Нужен Python 3.10+ и пакеты `numpy` и `Pillow`. Запуск нейросети описан в `docs/DATASET_V4.md`.

```powershell
python scripts/generate_demo.py
python -m app.server
```

После запуска откройте `http://127.0.0.1:8000`.

На Windows можно просто запустить `start_falcon.bat`: он проверит зависимости, при необходимости установит их и запустит сервис.

Если пакетов нет:

```powershell
python -m pip install -r requirements.txt
```

Запуск в контейнере:

```powershell
docker build -t falcon-mvp .
docker run --rm -p 8000:8000 -v falcon-data:/opt/falcon/data falcon-mvp
```

Или одной командой:

```powershell
docker compose up --build
```

## API

- `GET /api/health` — состояние сервиса;
- `GET /api/vehicles` — зарегистрированные профили;
- `POST /api/vehicles/register` — регистрация изображения;
- `POST /api/search` — поиск совпадений;
- `DELETE /api/vehicles/{vehicle_id}` — удаление профиля.

Изображение передаётся как Data URL или Base64 в поле `image_base64`. Если передан полный кадр, добавьте `bbox` как массив `[x, y, width, height]` или объект `{x, y, w, h}`. Без `bbox` изображение считается готовым кропом автомобиля.

```json
{
  "vehicle_id": "car-001",
  "image_base64": "data:image/jpeg;base64,...",
  "bbox": {"x": 120, "y": 80, "w": 640, "h": 360},
  "metadata": {"make": "Lada", "model": "Vesta", "color": "white"}
}
```

## Ограничения MVP

Текущий отпечаток — воспроизводимый baseline без нейросетевой модели. Он подходит для демонстрации полного контура решения и первичной проверки гипотез. Детектор не нужен: по условиям задачи BBox уже предоставляется. Для конкурсного качества после получения данных нужно добавить обученный vehicle ReID-энкодер и откалибровать порог отказа. Подробности — в [docs/PROJECT.md](docs/PROJECT.md).

Формат датасета, аудит и оценка описаны в [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md).
Инструкция по передаче конкурсных данных находится в [docs/DATASET_HANDOFF.md](docs/DATASET_HANDOFF.md).

После калибровки пороги можно передать через переменные среды `FALCON_REVIEW_THRESHOLD` и `FALCON_HIGH_THRESHOLD` без изменения кода.
